# Active Noise Cancelling system firmware
## Введение
Этот репозиторий содержит исходный код системы активного шумоподавления для компактной бытовой приточной установки.

## Техническая информация
Текущая версия предназначена для микроконтроллера stm32l432. Используются внетренние аппаратные ADC и DAC, аналоговые микрофоны с усилителем MAX9814.

## Электрическая схема

| Сигнал                      | Пин контроллера    |
|-----------------------------|--------------------|
| Опорный микрофон            | PA6 (ADC1 ch. 11)  |
| Микрофон ошибки             | PA7 (ADC1 ch. 12)  |
| Выход на усилитель динамика | PA4 (DAC1 OUT1)    |
| Отладочный UART Rx (опц.)   | PA15               |
| Отладочный UART Tx (опц.)   | PA2                |
